# Photos

Dépose ici une image nommée `vintagestory.jpg` (n'importe quelle photo ou capture d'écran du jeu). Elle s'affichera automatiquement en couverture sur la page d'accueil et sur la page du jeu.

Tant qu'il n'y a pas de fichier, un dégradé orange s'affiche à la place — pas de souci si tu n'as pas encore de photo.

Pour un autre jeu plus tard, ajoute une image `nomdujeu.jpg` ici, puis référence-la dans `index.html` et crée une page `nomdujeu.html` sur le modèle de `vintagestory.html`.
